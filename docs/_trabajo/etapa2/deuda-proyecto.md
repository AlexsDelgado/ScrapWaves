# Etapa 2 — Deuda técnica a nivel proyecto y preparación de release (23-09-2026)

Base: `main` @ `53ef237`, Unity `6000.3.13f1`, URP 17.3. Esto es una auditoría de solo lectura del repositorio, el build, los paquetes, los tests, los assets y el proceso. No es una revisión de código script por script. Todo lo que aparece está verificado con comandos o archivos, y la evidencia está en cada fila. Los hallazgos que vienen de la etapa 1 se marcan como `E1-#`, con el número o la sección de `etapa1-diferencias.md`.

## Quick wins

Todos se hacen en menos de una hora y no cambian el gameplay.

1. **Build Settings:** deshabilitar o sacar `WeaponTestingSandbox`, `enemiesTesting`, `test_balance` y `SampleScene` (P-02).
2. **Guardas de debug:** agregar `#if UNITY_EDITOR || DEVELOPMENT_BUILD` o `if (!Debug.isDebugBuild) Destroy(this)` en los 5 componentes de debug y en `QaPanels` (P-01).
3. **`.gitignore`:** agregar `*.rar`, `*.zip` y `*.7z`. Crear un `.gitattributes` mínimo con EOL para el YAML de Unity (P-04, P-05).
4. **Limpieza de plantilla:** borrar `SampleScene` con sus lightmaps, `TutorialInfo`, `Readme.asset`, `New Lighting Settings`, `Tree_Textures`, `Assets/Temp` y `Assets/_Recovery`. Son unos 75 MB (P-06).
5. **Logs:** borrar los 4 `Debug.Log` de slide en `PlayerMovement.cs` (P-12).
6. **Ramas y docs:** borrar las ramas ya mergeadas, commitear `docs/` y crear el `README.md` (P-08, P-13).
7. **Paquetes:** quitar `com.unity.pipeline` (experimental) y `com.unity.visualscripting` (P-16).
8. **Íconos:** bajar el Max Size de los íconos de logros a 256 o 512 (P-18).

## Checklist de release

- [ ] Build Settings o un Build Profile "Release" con solo `TitleScreen` y `GameplayScene`.
- [ ] Herramientas de debug desactivadas en el build no-development: F1, F3, P, Numpad ±, Numpad 0, profiler HUD, `BalanceTuningHub` y el botón DEV max upgrades / 9999 scrap (E1-C).
- [ ] `productName`, `companyName`, `applicationIdentifier` y `bundleVersion` definidos y definitivos, porque afectan la ruta del save.
- [ ] Ícono del ejecutable y splash revisados. Hoy el ícono es `Prefabs/UI/Logo.png`.
- [ ] Standalone con IL2CPP, calidad PC por defecto y vSync o límite de FPS.
- [ ] `Debug.Log` de runtime eliminados o bajo `[Conditional]`. Revisar el `Player.log` de un build.
- [ ] Bugs de gameplay de la etapa 1 resueltos o aceptados: E1-6 (variantes que nunca salen), E1-9 (crítico al 100 % por powerup), E1-7 (overheat permanente) y E1-C (scavenging inconsistente).
- [ ] Tests EditMode en verde y una prueba manual de humo del ciclo completo: título, run, boss, puerta, fin de run y meta.
- [ ] `main` limpio: sin cambios de TMP ni de ProjectSettings pendientes, con un tag `vX.Y` en el commit del build.
- [ ] Build fuera del repo: publicarlo como GitHub Release o en un almacenamiento externo, nunca commiteado.
